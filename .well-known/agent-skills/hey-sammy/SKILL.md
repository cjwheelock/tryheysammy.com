# Discover Hey Sammy

Use this skill when an agent needs public, machine-readable information about Hey Sammy, its mission, or its published content.

## Instructions

1. Read `https://tryheysammy.com/api/index.json` for the current discovery index.
2. Read `https://tryheysammy.com/index.html.md` for a concise Markdown overview of Hey Sammy.
3. Read `https://tryheysammy.com/llms.txt` to find the about page and published essays.
4. Use `https://tryheysammy.com/.well-known/api-catalog` to discover API descriptions and health resources.
5. Treat all listed endpoints as public and read-only. Do not send credentials or user data.

## Intended use

This skill supports content discovery and product understanding. It does not authorize account creation, private API access, event registration, or actions on a user's behalf.
